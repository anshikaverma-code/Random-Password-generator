Description

This project is a Python-based Random Password Generator that creates strong and customizable passwords. Users can specify the password length and choose whether to include uppercase letters, lowercase letters, numbers, and special characters. The program ensures a secure and randomized password is generated based on the selected options.

Features
Custom password length
Include/exclude uppercase letters
Include/exclude lowercase letters
Include/exclude numbers
Include/exclude special characters
Input validation
Random and secure password generation

Technologies Used

Python
random module
string module

How to Run

Clone the repository.
Run the Python file.
Enter the required inputs.
Get your randomly generated password.
